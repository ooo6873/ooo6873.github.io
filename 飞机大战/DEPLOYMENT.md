## 方案一：局域网分享（立即可用）

**适用场景：** 朋友在身边，同一WiFi网络下

**步骤：**
1. 确保手机和电脑连接同一个WiFi
2. 手机浏览器打开：**http://192.168.1.5:8080**
3. 开始游戏！

**优点：** 无需额外配置，延迟最低  
**缺点：** 必须在同一网络下

---

## 方案二：免费静态托管（推荐，永久可用）

### GitHub Pages（推荐）

**步骤：**
1. 注册 GitHub 账号：https://github.com
2. 创建新仓库，命名为 `airplane-battle`（或其他名称）
3. 上传 `index.html` 文件到仓库
4. 进入仓库 Settings → Pages
5. Source 选择 `main` 分支，点击 Save
6. 等待 1-2 分钟，访问链接会显示为：
   ```
   https://你的用户名.github.io/airplane-battle/
   ```
7. 分享此链接给任何人，手机点开即玩！

**优点：** 
- 完全免费，永久可用
- 全球访问速度快
- 自动 HTTPS 加密

**缺点：** 需要 GitHub 账号

---

### Netlify（最简单）

**步骤：**
1. 访问 https://www.netlify.com
2. 注册账号（可用 GitHub/Google 登录）
3. 登录后，直接将 `index.html` 文件拖拽到页面
4. 自动生成链接，如：
   ```
   https://随机名称.netlify.app
   ```
5. 分享此链接即可

**优点：**
- 无需任何技术知识
- 30秒完成部署
- 支持自定义域名

---

### Vercel

**步骤：**
1. 访问 https://vercel.com
2. 注册账号（可用 GitHub 登录）
3. 点击 "New Project"
4. 上传文件或连接 GitHub 仓库
5. 自动生成链接

---

## 方案三：内网穿透（临时公网访问）

### 使用 cpolar（国内推荐）

**步骤：**
1. 注册 cpolar：https://www.cpolar.com
2. 下载安装客户端
3. 登录并获取 authtoken
4. 运行命令：
   ```bash
   cpolar http 8080
   ```
5. 获得公网链接，如：
   ```
   https://xxxxxx.cpolar.io
   ```
6. 分享此链接

**优点：** 国内访问速度快  
**缺点：** 免费版链接会变，需要保持程序运行

---

## 方案四：云服务器部署（专业方案）

如果你有云服务器（阿里云、腾讯云等）：

**步骤：**
1. 将 `index.html` 上传到服务器
2. 安装 Nginx：
   ```bash
   sudo apt install nginx  # Ubuntu/Debian
   sudo yum install nginx  # CentOS
   ```
3. 将文件放到 `/var/www/html/` 目录
4. 启动 Nginx：
   ```bash
   sudo systemctl start nginx
   ```
5. 访问服务器 IP 即可

## 常见问题

**Q: 为什么手机访问不了局域网地址？**  
A: 确保手机和电脑在同一WiFi，且关闭了AP隔离。

**Q: GitHub Pages 部署后链接打不开？**  
A: 等待 2-3 分钟，检查文件是否在主分支根目录。

**Q: 游戏加载很慢？**  
A: 正常，首次加载需要下载资源，后续会有缓存。

**Q: 可以绑定自己的域名吗？**  
A: 可以，GitHub Pages 和 Netlify 都支持自定义域名。
